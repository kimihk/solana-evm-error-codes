# Tx Doctor — Transaction Failure Diagnostic

Free diagnostic reference for failed blockchain transactions.
Paste any error code to get plain-language causes and step-by-step fixes.

**→ https://txdoctor.app**

## Covers

- Solana: slippage, BlockhashNotFound, InsufficientFundsForFee, compute budget errors
- EVM: execution reverted, ERC-20 allowance, gas estimation failures
- Bitcoin & TRON: stuck mempool fees, out-of-energy, RBF replacement
